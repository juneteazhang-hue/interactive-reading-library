# 互动精读资源库

一个无需服务器的英语互动精读网站，可直接部署到 GitHub Pages。

## 当前内容

- 《Rise of the Earth Dragon》八段互动精读
- 本地朗读、重点词汇、完整翻译、布鲁姆阅读题
- 核心句式解析与仿写练习
- 第九页八图翻转复述
- 九组文章生成与审核提示词

## 本地使用

直接打开 `index.html`。部分浏览器对本地脚本有限制时，可使用任意静态文件服务器预览。

## 新增文章

查看 `docs/新增文章操作指南.md` 和 `docs/提示词套装.md`。公开发布前必须确认内容传播权限，并确保审核报告的未关闭阻断项为 0。

## 测试

```bash
node --test tests/library.test.mjs
```
