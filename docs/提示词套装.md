# 互动精读资源库：九组可复用提示词

使用方法：把方括号中的内容替换为本次资料。建议依次使用 1–9，不要跳过审核。任何审核出现“阻断发布”，必须修订后重新审核。

## 1. 总控生成提示词

```text
你是一名小学高年级至初中英语精读课程设计师和静态网页内容工程师。

输入：
- 原文：[粘贴全文或提供文件]
- 目标年级：[小学中高年级/初中]
- 默认口音：[美式英语]
- 故事名称：[名称]
- 图片风格：[绚丽、原创、动画电影风]

目标：把原文制作成互动精读资源库中的一个故事单元。每个单元必须是 8 个语义文段、8 张统一风格插图和第 9 页八图复述。若原文过长，拆成多个八段单元；若不足以形成 8 个有效单元，标记“需要与相邻章节合并”，不得凑段。

每段必须生成：完整英文原文、忠实中文翻译、4 个重点词（IPA、词性、中文释义、英文解释）、2 道统一布鲁姆四选一题、1–2 个核心句式、逐段音频路径和图片路径。每个核心句式含句型骨架、中文解析、词组、双语例句及 2 道仿写。第 9 页生成 8 张双语复述卡。

工作顺序：分段报告 → 翻译与词汇 → 标准题目 → 句式与仿写 → 图片设定与八幅图 → 八图复述 → 教学审核 → 技术审核。输出 BOOK_DATA、segmentation-report.md、audit-report.md；存在阻断项时不要发布。
```

## 2. 语义分段与完整翻译提示词

```text
请把以下原文划分为固定 8 个精读文段。语义完整优先，不按句数机械切割。

目标年级：[年级]
原文：[全文]

分段标准：小学每段建议 60–110 词，初中 90–160 词；场景、时间、地点、行动目标、对话话题、情绪转折或知识主题改变时可以分段。不要截断引语、指代、固定句式或直接因果。保持所有原句、顺序和标点，不漏句、不重复、不改写。

先输出 segmentation-report.md 表格：页码、起始句、结束句、词数、内容类型（story/dialogue/informational/mixed）、分段理由、与前后页关系。再逐段输出完整中文翻译。翻译必须覆盖人物、动作、时间、情绪、因果、转折和场景细节；统一人名地名；不得用概括代替全文翻译，不得增加原文没有的因果。

最后自检：逐句对齐原文，报告漏译、错译、增译、指代、时态和专名问题。无法合理形成 8 段时输出“阻断发布：需要与相邻章节合并”。
```

## 3. 重点词汇提示词

```text
针对以下 8 个文段，每段选择恰好 4 个最有教学价值的词或短语。

目标年级：[年级]
口音：[美式英语]
文段：[八段原文]

每项输出：[原文词形, IPA, 当前语境词性, 中文语境释义, 适龄英文解释]。

审核要求：词必须真实出现于该段；IPA 与词形和口音匹配；词性必须是该词在当前句中的实际用法；中文释义对应语境；英文解释自然且不使用更难的词。检查复数、过去式、分词、派生词和短语动词。不要选四个同类型简单名词，也不要用词根释义替代当前词形。
```

## 4. 布鲁姆阅读题提示词

```text
为每个文段生成恰好 2 道四选一题，顺序和层级固定。

第 1 题：remember 或 understand，检查该段最重要的事实、行动、地点、指代、顺序或主旨，答案可从当前段直接找到。
第 2 题：apply 或 analyze。故事选人物动机、因果、情绪变化、伏笔、证据推断或情节作用；对话选意图、语气或关系；说明文选因果、比较、分类、证据或应用。答案必须由当前段 1–2 个线索支持。

每题输出：level、skill、question、choices（恰好 4 个）、answer（0–3）、evidence、rationale。skill 从 key-detail、main-idea、sequence、reference、cause-effect、character-motivation、inference、author-purpose、compare-contrast、application 中选择。

四个选项保持相同语法形式和相近长度；三个干扰项分别来自关系错误的信息、常见误解、缺少证据的表面合理推断。禁止“以上都是/都不是”、双重否定和荒谬选项。整篇正确答案位置均衡。rationale 解释正确项和主要干扰项。发现两个合理答案即标记“阻断发布”。
```

## 5. 核心句式提示词

```text
从每段原文中原样选择 1 个最有迁移价值的核心句；句型丰富时最多 2 个。不要改写原句。

为每个句式输出：sentence、中文句意、pattern（可复用句型骨架）、grammar（适合[年级]的中文解析）、phrases（2–3 个）、example、exampleTranslation、exercises（恰好 2 道）。

练习 1 检查套用句型结构；练习 2 检查替换语境。每题输出中文 prompt、自然正确的英文 answer、明确的结构 hint。答案必须真正使用目标句型。审核时检查成分、时态、语态、非谓语、从句和固定搭配，不得用未经解释的术语或错误简化。
```

## 6. 八幅图片生成提示词

```text
根据 8 个文段设计 8 张横版 16:9 原创动画电影风场景图。

先输出 Style Bible：主角年龄、脸型、发型、服装、配色、身高比例；配角和关键道具；世界观色彩；镜头、光影、材质和画幅。之后每张图都必须复用同一设定。

统一要求：色彩绚丽、电影级光影、空间层次明确、儿童友好、无文字、无水印、无气泡、无答案标记；不复制现有影视角色、标志或特定电影画面。每张图准确表现对应文段的主要人物、地点、动作和情绪，同时用构图变化避免 8 张画面完全相同。

逐图输出：页码、故事瞬间、人物一致性约束、环境、动作、情绪、镜头、光线、主色、完整英文图片提示词、负面提示词。最后对照 Style Bible 审核角色、服装、道具、画幅和色彩一致性。
```

## 7. 八图复述页提示词

```text
根据 8 个文段和 8 张图，为小学高年级学生制作第 9 页复述支架。

每张卡输出：title、image、keywords（2–4 个英文词组）、retell（1–2 句英文，每句建议 6–14 词）、cueZh（一句中文提示）。故事统一使用第三人称和一般过去时。关键词优先复用该段重点词和动作短语。

八卡依次覆盖开端、关键行动、冲突/发现、转折和结果。适量使用 First、Then、Next、After that、Finally，避免每句机械重复。中文只提示情节，不逐字翻译英文。最后输出“八句连读版”，检查连贯、无重复、无漏掉关键事件，并确认每张卡与同编号文段和图片一致。
```

## 8. 教学内容审核提示词

```text
你是独立审核员，不参与原内容生成。请逐页审核以下 BOOK_DATA、segmentation-report.md 和图片说明。

审核维度：
1. 分段：8 段、无漏句/重复/乱序/截断，词数和分段理由合理。
2. 翻译：逐句完整、专名统一、时态/语态/否定/因果/指代准确，无概括代替或额外推断。
3. 词汇：原文存在、IPA 准确、词性符合语境、双语释义适龄自然。
4. 题目：基础＋高阶顺序、唯一答案、选项平衡、证据和 rationale 匹配。
5. 句式：原句匹配、结构准确、例句自然、两道仿写及答案真正使用目标结构。
6. 图片：8 张与文段对应，角色、服装、色彩、光影和画幅一致。
7. 复述：8 卡对应、英语正确且适合小学生，中文提示准确，八句连读完整连贯。

输出 audit-report.md。每项标记“通过”“建议修订”或“阻断发布”，写清页码、字段、问题原因、修订内容。只要存在答案歧义、翻译漏错、IPA/词性错误、核心句分析错误、图片错配或复述语法错误，就必须阻断发布。修订后重新审核，最终列出“未关闭阻断项：0”。
```

## 9. 技术质量检查与发布提示词

```text
请对互动精读静态项目执行发布前技术检查。

验证：catalog 与书目目录一一对应；每书 8 页、8 图、8 音频、8 复述卡、segmentation-report.md、audit-report.md；每页 4 词、2 题、1–2 句式；图片音频相对路径存在；核心句出现在原文；答案索引 0–3；题目层级顺序正确；第 9 页有 8 张可点击/键盘翻转且能翻回的卡片；移动端和 prefers-reduced-motion 可用；无绝对本地路径、密钥或私人资料。

运行 JavaScript 语法检查和全部自动化测试。确认 audit-report.md 的“未关闭阻断项”为 0。任何失败都停止发布并给出文件、页码和修复建议。全部通过后再推送 GitHub，并验证主页及 reader.html?book=[文章代号] 均可公开访问。
```
