# 新增文章操作指南

1. 准备具有公开发布权限的英文原文，确定目标年级和美式/英式口音。
2. 按《提示词套装》1–7 依次生成分段、翻译、词汇、题目、句式、图片和复述内容。
3. 使用第 8 组提示词独立审核，修复全部“阻断发布”，保存 `segmentation-report.md` 与 `audit-report.md`。
4. 复制 `books/_template/` 为新的英文短横线文章代号目录，填入 `content.js`、8 张图和 8 段音频。
5. 在 `scripts/catalog.js` 添加书目卡片信息。
6. 使用第 9 组提示词及 `node --test tests/library.test.mjs` 检查。
7. 本地预览首页、8 个阅读页和第 9 页复述墙。
8. 提交并推送 GitHub。Pages 更新后，把 `reader.html?book=文章代号` 链接发给学生。

公开发布前请确认文章、音频和图片均具有公开传播权限，不要把学生信息、账号、密钥或私人文件放进仓库。
